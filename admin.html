홈페이지 관리

GitHub 저장소에 직접 저장하는 방식입니다. 처음 한 번만 토큰을 입력하면 이 기기에서 계속 쓸 수 있습니다.

GitHub 연결

토큰은 이 브라우저에만 저장되고, GitHub 외의 곳으로는 보내지 않습니다.

홈페이지 파일이 올라가 있는 GitHub 저장소입니다.
토큰 만드는 방법
  1. GitHub에 로그인한 뒤 새 Fine-grained 토큰 만들기 페이지를 엽니다.
  2. Token name에 아무 이름(예: 홈페이지 관리)을 적고, Expiration은 원하는 기간으로 정합니다.
  3. Repository access에서 Only select repositories를 고르고 홈페이지 저장소 하나만 선택합니다.
  4. Permissions → Repository permissions에서 Contents와 Actions를 각각 Read and write로 바꿉니다.
  5. Generate token을 누르고 나온 문자열을 복사해 위 칸에 붙여 넣습니다.
연결된 저장소 · 저장하면 1~2분 뒤 사이트에 반영됩니다.
