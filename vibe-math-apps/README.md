# 바이브 코딩 수학 수업 앱 설계 원리 예시

예비 초등교사를 위한 '바이브 코딩을 이용한 나만의 수학 수업 앱 만들기' 수업 자료입니다.
수학교육용 공학 도구의 설계 원리 7가지를 원리마다 **AI 기본값대로 만든 앱(X)** 과 **교수학적으로 다듬은 앱(O)** 으로 비교해 볼 수 있습니다.

바로 열기: https://mathriller.github.io/vibe-math-apps/

| 층 | 원리 | 예시 |
|---|---|---|
| A 수학적 충실성 | 1. 수학적 정확성과 구조를 보존하라 | 분수 막대·분수 덧셈 |
| B 인지적 충실성 | 2. 학습 목표에 맞게 블랙박스의 범위를 정하라 | 수모형 받아올림 |
| | 3. 표상을 연결하되, 필요한 표상만 골라 담아라 | 분수 막대와 수직선 |
| | 4. 발달 수준에 맞게 화면을 설계하라 | 2학년 시계 |
| C 교수학적 충실성 | 5. 변이와 불변을 탐구할 공간을 만들어라 | 둘레가 같은 직사각형 |
| | 6. 판정 대신 결과를 보여 주는 피드백을 주라 | 정육면체 전개도 접기 |
| D 수업 정합성 | 7. 교사가 수업 안에서 조율할 수 있게 하라 | 곱셈 배열 나누기 |

빌드 과정 없는 정적 HTML/JS입니다. 서울교육대학교 수학교육과.
